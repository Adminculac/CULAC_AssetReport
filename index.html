☁️ ใช้ข้อมูลร่วมกันทั้งศูนย์ (Google Sheet)

ใส่ URL ของ Google Apps Script (ไฟล์ v25_Code.gs) เพื่อให้ทุกคนเห็นข้อมูลชุดเดียวกัน ถ้าเว้นว่าง ระบบจะเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น
วิธีตั้งค่า (ทำครั้งเดียว)
  1. สร้าง Google Sheet ใหม่ → เมนู ส่วนขยาย → Apps Script → วางโค้ดจากไฟล์ v25_Code.gs แทนของเดิม → บันทึก
  2. กด ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท เว็บแอป → เรียกใช้ในฐานะ "ฉัน" → ผู้ที่มีสิทธิ์เข้าถึง "ทุกคน" → ทำให้ใช้งานได้
  3. คัดลอก URL ที่ลงท้ายด้วย /exec มาวางในช่องด้านบน → กด บันทึก & ทดสอบ → กด ส่งข้อมูลในเครื่องขึ้น Sheet
  4. ให้ทุกคนเห็นข้อมูลอัตโนมัติ: เปิดไฟล์ HTML นี้ด้วย Notepad แก้บรรทัด const DEFAULT_GAS_URL = '' ใส่ URL เดียวกัน แล้วนำขึ้น GitHub Pages
  5. บุคลากรเห็นเฉพาะหน้าค้นหา · ผู้ดูแลกด 🔒 ท้ายหน้า แล้วใส่รหัสผู้ดูแล เพื่อเข้าหลังบ้าน
